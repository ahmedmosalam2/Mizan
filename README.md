# Agentic AI Benchmark Project

This project aims to benchmark and compare popular Agentic AI frameworks (CrewAI, LangGraph, AutoGen, etc.) across various complex tasks.

## Setup

1. Copy `.env.example` to `.env` and fill in your keys.
2. Install dependencies: `pip install -r requirements.txt` 
3. Run the FastAPI server: `uvicorn api.main:app --reload`
